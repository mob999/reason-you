# Reason You

Reason You is a developer CLI that explains the most recent failed shell command.

## Development

```bash
bun install
```

```bash
bun run check
bun test
bun run build
```

## Usage

```bash
./dist/reasonyou init
./dist/reasonyou doctor
./dist/reasonyou
```

Set `OPENAI_API_KEY` before running live analysis.

This project was created using `bun init` in Bun v1.3.13. Release binaries can be produced with `bun build --compile`.
